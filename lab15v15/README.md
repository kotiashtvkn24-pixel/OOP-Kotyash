
# Лабораторна робота №15

**Тема:** LINQ в дії: фільтри, join, агрегації. Продуктивність

**Варіант:** 15

**Виконав:** Котяш Тарас  
**Група:** КН-3/1

## Мета роботи

Навчитися використовувати LINQ для фільтрації, об'єднання та агрегації даних, а також вимірювати час виконання запитів.

## Опис програми

Створено два класи:

- Product — товар (Id, Name, Price, SupplierId).
- Supplier — постачальник (Id, Name, Country).

Для перевірки використано 15 товарів та 5 постачальників.

## Виконані завдання

1. Фільтрація — пошук товарів постачальника Global Supplies з ціною менше 100.
2. Join — об'єднання товарів з постачальниками.
3. Агрегація — підрахунок кількості товарів кожного постачальника.
4. Пошук — знаходження найдешевшого товару.

Для кожного завдання використано синтаксис запитів і синтаксис методів LINQ.

Час виконання вимірюється за допомогою Stopwatch.

## Висновок

Під час лабораторної роботи було створено програму для управління товарами на складі. Було використано LINQ для фільтрації, об'єднання та групування даних. Також було виміряно час виконання запитів за допомогою Stopwatch. Отримані результати показали, що LINQ спрощує роботу з колекціями даних.
