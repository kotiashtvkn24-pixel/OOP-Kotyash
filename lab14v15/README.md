
# Лабораторна робота №14

**Тема:** HashSet, Queue, Stack: практичні сценарії

**Варіант:** 15

**Виконав:** Котяш Тарас  
**Група:** КН-3/1

## Мета роботи

Навчитися використовувати колекції HashSet, Queue та Stack у C#.

## Виконання роботи

1. HashSet — зберігає унікальних користувачів, у яких увімкнені сповіщення.
2. Queue — зберігає сповіщення в черзі та обробляє їх за принципом FIFO.
3. Stack — зберігає історію прочитаних сповіщень за принципом LIFO.



## Приклад виводу програми

```text
=== HASHSET ===
Користувача додано: Taras
Користувача додано: Ivan
Користувача додано: Olena
Користувач вже існує: Taras

Користувачі зі сповіщеннями:
Taras
Ivan
Olena

=== QUEUE ===
Додано сповіщення: Нове повідомлення
Додано сповіщення: Оновлення програми
Додано сповіщення: Нове замовлення
Наступне сповіщення: Нове повідомлення
Прочитано: Нове повідомлення
Прочитано: Оновлення програми

=== STACK ===

Історія прочитаних сповіщень:
Оновлення програми
Нове повідомлення
Останнє прочитане: Оновлення програми

Історія прочитаних сповіщень:
Нове повідомлення

Кінець програми
```


## Висновок

Під час лабораторної роботи було створено систему обробки сповіщень. Було використано HashSet для унікальних користувачів, Queue для черги сповіщень та Stack для історії прочитаних повідомлень.
