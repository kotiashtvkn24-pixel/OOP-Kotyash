# Лабораторна робота №12 — Generic-методи (Map / Filter / Reduce / ForEach / Any)

**Проєкт:** lab12v1
**Варіант:** 1 — Map, Filter, Reduce, ForEach, Any
**Дисципліна:** Об'єктно-орієнтоване програмування

## Мета

Навчитися створювати узагальнені (generic) методи для повторного використання логіки, використовувати делегати `Func`, `Action`, `Predicate` як параметри поведінки та реалізовувати типові операції над колекціями.

## Реалізовані методи (клас `FunctionalUtils`)

| Метод | Сигнатура | Делегат |
|---|---|---|
| Map | `List<TResult> Map<T, TResult>(List<T>, Func<T, TResult>)` | `Func<T, TResult>` |
| Filter | `List<T> Filter<T>(List<T>, Func<T, bool>)` | `Func<T, bool>` |
| Reduce | `TAccumulate Reduce<T, TAccumulate>(List<T>, TAccumulate, Func<TAccumulate, T, TAccumulate>)` | `Func<TAccumulate, T, TAccumulate>` |
| ForEach | `void ForEach<T>(List<T>, Action<T>)` | `Action<T>` |
| Any | `bool Any<T>(List<T>, Predicate<T>)` | `Predicate<T>` |

Обмеження типів (`where T : IComparable<T>` тощо) для цих п'яти методів не потрібні: вони не порівнюють і не сортують елементи, а лише передають їх делегатам.

## Структура

- `FunctionalUtils.cs` — generic-методи
- `Person.cs` — тестовий клас (`Name`, `Age`, `Salary`)
- `Program.cs` — демонстрація з `int`, `string` і `Person`

## Відповіді на контрольні запитання

1. **Generic-методи** працюють з будь-яким типом, який вказується як параметр `<T>`. Переваги: повторне використання коду, типобезпека, відсутність boxing та приведення типів.
2. **Func<T, TResult>** повертає значення, **Action<T>** нічого не повертає (`void`). `Predicate<T>` — окремий випадок, що повертає `bool`.
3. **Функції вищого порядку** приймають інші функції як параметри або повертають їх. Приклади: `Map`, `Filter`, `Reduce`, `ForEach`.
4. **Обмеження (constraints)** вказують, які можливості має мати тип `T` (наприклад, `IComparable<T>` для порівняння), і дозволяють викликати відповідні методи всередині generic-коду.
5. **Лямбда-вирази** дозволяють передати поведінку коротко, прямо в місці виклику (`x => x * x`), без окремого іменованого методу.
